# Contributing

## Development Environment

Node.js `^22.19.0` or `>=24` is required.

Install dependencies:

```sh
npm install --ignore-scripts
```

Run checks:

```sh
npm run check
```

Run package checks:

```sh
npm run pack:check
```

## Change Guidelines

Each commit has one topic.
User-visible changes update the README.
Commits do not include API keys.
Commits do not include personal configuration.
Commits do not include session logs.

## Pull Requests

A pull request includes a short purpose statement.
A pull request includes verification commands.
A pull request keeps unrelated changes out of scope.
